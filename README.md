# Sistema de Atención de Clientes – Carnicería El Buen Corte

## Descripción del proyecto

Este proyecto fue desarrollado como parte del trabajo colaborativo de la asignatura **Estructura de Datos Dinámicos**, correspondiente a la carrera de Técnico de Nivel Superior en Analista Programador del CFT CENCO.

El programa consiste en una simulación del funcionamiento de una carnicería llamada *El Buen Corte*, desarrollada en lenguaje C++. Su propósito es demostrar, mediante un ejemplo cotidiano, cómo se pueden utilizar distintas estructuras de datos dinámicas para organizar y administrar información.

Para ello, se implementaron tres estructuras fundamentales:

- **Cola (FIFO):** permite registrar los turnos de los clientes y atenderlos según su orden de llegada.
- **Lista enlazada simple:** permite agregar, buscar y eliminar productos de un pedido, además de calcular el valor de la compra.
- **Pila (LIFO):** permite almacenar las boletas generadas y retirar el último registro ingresado.

El programa cuenta con un menú interactivo que permite simular la llegada de clientes, la preparación de pedidos, el cobro y la consulta de las boletas emitidas.

## Objetivo

Aplicar los conocimientos adquiridos sobre listas enlazadas, pilas, colas y manejo de punteros en C++, mediante el desarrollo de una aplicación práctica que facilite la comprensión de estas estructuras y sus operaciones.

## Código fuente

El proyecto se encuentra desarrollado en **C++** y su código está disponible en el archivo `carniceria.cpp`.

Se trata de una aplicación educativa de consola. Los registros se mantienen temporalmente durante la ejecución del programa, por lo que no utiliza una base de datos ni constituye un sistema comercial de ventas.
